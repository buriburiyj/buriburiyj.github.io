# 1. 그룹사 개요

참가자가 시나리오에 등장하는 회사들의 관계를 빠르게 파악할 수 있도록,
지주회사와 자회사가 각각 무슨 사업을 하고 어떻게 연결되어 있는지 간단히
정리한다. 상세 재무·이슈 데이터는 각 트랙 자료를 참고한다.

    Aurora Holdings (지주회사)
     ├─ Corevia Cosmetics — 제조 자회사 (화장품 OEM/ODM)
     ├─ Masil Commerce — 유통 자회사 (자사몰·대리점, 더마 라인은 Corevia 100% 의존)
     └─ Celtonic Labs — 인수 검토 대상 (자회사 아님, 더마 활성원료 개발·생산)

## 1.1 Aurora Holdings — 지주회사

자회사 지분과 그룹 자금·전략·투자를 총괄한다. 직접 생산·판매 활동은 하지
않으며, Corevia·Masil이 올리는 자금 수요를 취합해 우선순위를 정하고
CEO·이사회 승인을 거쳐 집행한다. 현재 그룹이 쓸 수 있는 자금은 약 300억
원으로, 이를 어디에 배분할지가 CEO의 핵심 의사결정이다.

| 구분      | 내용                                                                  |
|-----------|-----------------------------------------------------------------------|
| 역할      | 자회사 지분·그룹 자금·전략·투자 총괄                                  |
| 연결 매출 | 약 5,880억 원                                                         |
| CEO       | 강세연 (취임 2년차) — 다음 주 이사회에서 그룹 90일 액션플랜 보고 예정 |

## 1.2 Corevia Cosmetics — 제조 자회사

기초·기능성 중심의 화장품을 제조하는 Aurora의 제조 자회사다. B2B
대형고객에게 직접 납품하는 동시에 계열사인 Masil에도 제품을 공급한다.
국내 공장(F1)과 해외 공장(F2)을 운영하며, 그중 F1은 더마 라인을 포함해
가동률이 87%로 포화 상태다.

| 구분      | 내용                                                  |
|-----------|-------------------------------------------------------|
| 사업      | 화장품 OEM/ODM 제조 (B2B 납품 + 계열 납품)            |
| 연매출    | 약 4,800억 원                                         |
| 공장      | F1(국내, 기초·더마·색조) / F2(해외, 헤어·바디·선케어) |
| 주요 고객 | C-101(대형 리테일러), C-102(홈쇼핑), 기타             |

## 1.3 Masil Commerce — 유통 자회사

자사몰과 대리점을 통해 화장품을 유통하는 Aurora의 유통 자회사다. 특히
성장률이 가장 높은 더마 라인은 전량 Corevia로부터 공급받는 구조여서, 두
회사의 실적이 서로 연동되어 있다.

| 구분   | 내용                                                                   |
|--------|------------------------------------------------------------------------|
| 사업   | 자사몰 + 대리점 유통 (더마 라인은 Corevia 100% 의존)                   |
| 연매출 | 약 1,800억 원 (GMV 최근 +25% 성장)                                     |
| 마케팅 | 연 지출 약 180억원 – 인플루언서 캠페인, 퍼포먼스 광고, 쿠폰프로모션 등 |

## 1.4 Celtonic Labs — 투자 검토 대상

Aurora의 자회사는 아니며, 더마 원료의 특정 공급처 의존도를 낮추기 위해
인수를 검토 중인 외부 회사다. 비건·기능성 활성원료를 개발·생산한다.

| 구분   | 내용                           |
|--------|--------------------------------|
| 사업   | 비건·기능성 활성원료 개발·생산 |
| 연매출 | 220억 원 (3년 CAGR 35%)        |

# 2. Business Process Map

참가자가 “이 데이터가 어느 업무에서 나오는가”를 스스로 추론할 수 있도록,
회사별 업무기술서 요약을 데이터룸 별첨(`business_process_map.md`)으로
제공한다. 표준 업무 흐름과 각 흐름에서 어떤 시스템·문서가 생성되는지만
보여준다.

## 2.1 Corevia Cosmetics — 제조 프로세스

    고객 수주 → 생산계획 → 원재료 구매 → 원재료 입고·검수 → 배치 생산 → 품질검사 → 출하 → 매출채권 → 현금 회수

| 단계             | 발생 시스템/문서                   | 참고                              |
|------------------|------------------------------------|-----------------------------------|
| 고객 수주        | 수주 시스템 (order_date 기준)      | 영업팀 관리                       |
| 생산계획         | 생산관리 시스템 (라인·공장 배정)   | F1(국내)/F2(해외)                 |
| 원재료 구매      | 구매 시스템 (발주일 환율 적용)     | 원료 마스터·공급처 마스터 참조    |
| 원재료 입고·검수 | 품질 시스템 (로트별 입고·검사)     | material_lot_master.csv 기록      |
| 배치 생산        | 생산 로그 (batch_id, lot 매핑)     | 배치×로트×라인 단위 기록          |
| 품질검사         | 품질 시스템 (규격 검사, 불량 로그) | 회사 품질정책 기준 적용           |
| 출하             | 출하 시스템 (ship_date 기준)       | 재무 매출 인식 기준일             |
| 매출채권         | 재무 시스템 (AR aging)             | 고객별 계약조건(원가연동 등) 연동 |
| 현금 회수        | 자금 시스템                        | 회수 이력 누적                    |

## 2.2 Masil Commerce — 유통 프로세스

    캠페인 → 광고·인플루언서 집행 → 고객 유입 → 주문 → 물류·배송 → 반품·환불 → 채널 정산 → 재고 보충 → 매입채무 지급 → 현금

| 단계      | 발생 시스템/문서                                 | 참고                                     |
|-----------|--------------------------------------------------|------------------------------------------|
| 캠페인    | 마케팅 시스템 (캠페인·인플루언서·광고비)         | attribution window 7일 고정              |
| 고객 유입 | 웹/앱 트래픽 시스템 (방문·유입경로 로그)         | mkt_traffic_inflow.csv, 주문 전환과 조인 |
| 주문      | 커머스 플랫폼 (order_date, GMV 발생)             | 채널별(자사몰/마켓플레이스/라이브)       |
| 물류·배송 | 물류센터 시스템 (출고·배송)                      | SKU별 재고 연동                          |
| 반품      | CS/반품 시스템 (refund_completed_date 기준 집계) | 쿠폰 중복 등 이상 탐지 대상              |
| 채널 정산 | 정산 시스템 (채널별 결제조건)                    | AR/AP와 연동                             |
| 재고 보충 | SCM 발주 시스템 (재고 커버 4주 평균 기준)        | Corevia 구매와 연결(더마)                |
| 현금      | 자금 시스템 (자금일보, covenant 매영업일 기준)   | 공식 전망 vs 실적 재계산 대조            |

## 2.3 Aurora Holdings — 그룹 의사결정 프로세스

    자회사 자금요청 → 리스크·기회 분석 → 그룹 현금 가용성 검토 → 투자·CAPEX·운전자금 우선순위화 → 투자조건 검토 → CEO·이사회 승인 → 집행·모니터링

| 단계             | 발생 시스템/문서     | 참고                          |
|------------------|----------------------|-------------------------------|
| 자회사 자금요청  | 그룹 자금관리 시스템 | Corevia/Masil 각 요청 취합    |
| 리스크·기회 분석 | 전략기획팀 검토자료  | 트랙별 Agent 산출물 활용 지점 |
| 투자조건 검토    | 실사·계약 검토 문서  | Celtonic Labs 등 외부 투자 건 |
| CEO·이사회 승인  | 이사회 안건·회의록   | 최종 배분 우선순위 결정       |
| 집행·모니터링    | 집행 관리 시스템     | 조건 변화 시 재평가           |

이 지도는 참가자에게 다음 여섯 가지를 스스로 설계하도록 유도하는 근거로
쓰인다: ① Agent가 어느 업무 이벤트에서 발동하는가, ② 어느 시스템의
데이터를 조회하는가, ③ 어느 조직이 결과를 받는가, ④ 어떤 행동은 자동화할
수 있는가, ⑤ 어떤 결정은 사람에게 넘어가야 하는가, ⑥ 얼마나 자주
재평가해야 하는가
